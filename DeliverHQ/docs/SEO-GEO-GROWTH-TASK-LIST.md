# UseGEO SEO/GEO Growth Task List

> 目标：让 UseGEO 通过 GEO 学习内容获取 SEO/GEO 流量，并通过广告、赞助、affiliate、partner referral / lead resale 变现。本文是后续 CR 切分的 backlog，不是单个 CR 的验收规格。

## 当前商业定位

UseGEO 不是自营完整 GEO 服务公司。核心商业路径是：

```text
GEO 学习内容
→ SEO/GEO 流量
→ 真实 Scanner
→ LLM Summary
→ Partner consent lead
→ Hot/Warm/Cold lead 分级
→ Partner pipeline / CSV 导出
→ Sponsor slots / affiliate / lead resale
```
