# Hi-Fi Spec: Public Page Visual Unification

## Visual system
- Public pages use a clean hero, content card, action panel, and foundation links.
- Money pages and generic pages share the same shell and typography scale.
- Duplicate H1 from content is removed to avoid amateur SEO/visual duplication.

## Acceptance
- Money pages h1_count=1 after deploy.
- Generic pages include `usegeo-public-page` classes.
- Homepage remains 200 and structurally unchanged.
