# Design Decisions: CR-010 Expand Money Pages

## Decision 1: Reuse existing WordPress page layout
CR-010 only updates content on three published WordPress pages. No theme PHP/CSS/JS changes are required.

## Decision 2: Use long-form commercial guide structure
Each page uses a consistent structure: short answer, main guide sections, checklist/buying criteria, common mistakes, FAQ, and bottom CTA.

## Decision 3: CTA language follows UseGEO positioning
CTAs point to the free Scanner and expert follow-up / partner match. They do not promise UseGEO will personally deliver a full GEO service.
