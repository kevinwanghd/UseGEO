# Hi-Fi Spec: Article Page Conversion Redesign

## Visual read
Clean editorial SaaS article page with strong type hierarchy, compact trust rail, calm content card, and one persistent scanner conversion route.

## Key changes
- Hero becomes a two-column editorial header with restrained metadata.
- Body uses readable width and fewer shadows.
- Sidebar has compact TOC and scanner card.
- Footer action panel replaces repeated mid/bottom CTA blocks.
- Foundation links become practical route cards, not noisy marketing tiles.

## Acceptance
- One H1.
- No long FAQ questions in TOC.
- CTA labels do not duplicate excessively.
- Mobile stacks: hero, sidebar, content, final action.
